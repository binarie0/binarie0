# Hello! ✨
My name is Zach, but I go by binarie in a lot of online settings. I'm a second-year student at RIT studying Game Design and Development and Psychology. I currently work for the osu! design team (you can find my profile [here](https://osu.ppy.sh/users/15632854)), creating videos to go alongside user generated content for tournaments. You can find all of my content and more on my [website](https://binarie.dev/)!

## Current Experience 🌱
I have experience working with C#, C++, HTML, CSS, and JavaScript. I also have experience working with Java and Python. In terms of applications, I have experience with the Adobe Suite, Autodesk Maya, and of course, GitHub. In terms of game engines, I've worked in Unity and Godot, and have plans to work inside Unreal within the year.

## Current Projects 🔭
At any point in time, I'm most likely working on a video for the osu! design team or for a commission. But, I always am working on school projects and some osu!-related content. More recently, I worked a bit on [Storybrew](https://github.com/Damnae/storybrew) to add a few quality of life features (binary search algorithm to build dynamic content with easing, helping with some math for the transform UI, adding undo and redo capabilities for the transform UI, adding a screenshot button, and re-enabling additional dependencies). I am also working on website development in Svelte for [echoes](https://echoes-vip.org), a project ran by RIT students and monitored by faculty for credits.
